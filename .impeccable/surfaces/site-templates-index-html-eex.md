# Surface brief: armless site (landing page + docs)

Scope: landing page (Persuade) and docs (Read). Replaces the first direction (parts cabinet), which the user rejected.

Pinned by the user: a console-like look; showcase armless running in the browser; a live memory element; a load running on the machine that the visitor can stop with ctrl+c to use the console. Not the "docs read from inside the machine" idea. The roll does not apply: this direction is the user's.

Audience: web and Rust developers deciding whether armless can run their guest; curious readers.
Proof: a real machine in the tab and armless's own memory report. No benchmarks, no users.

## Direction contract

THESIS: The page is the machine's screen. A running shell and armless's memory report sit above the fold, and the visitor can take the shell over. Refuses the headline-over-screenshot landing page.

OWN-WORLD: After vitro.run, pinned by the user: warm near-black ground, Space Mono throughout, thin rules, state by brightness, colour only for failure. The console is the one darker region.

STORY: The visitor sees a Linux program running, the memory moving, presses ctrl+c, types, then reads the docs.

FIRST VIEWPORT: A short hero (headline, one sentence, two buttons) over the machine: console left, memory pane right, in one thin-ruled box. A one-line caption says it is user mode with no kernel.

FORM: Minimalist dark, after vitro.run; pinned by the user, not rolled (seed: none).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
